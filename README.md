# module-1_aula-3_exercicio-1

Este repositório contém materiais sobre configuração de agentes e instruções customizadas para GitHub Copilot, além dos requisitos para um projeto de API de séries e filmes.

## Objetivo do Projeto

Este repositório serve como referência para:
- Entender como estruturar agentes customizados
- Aprender a criar instruções efetivas
- Explorar padrões de desenvolvimento com suporte de IA


## Arquivos do Repositório

### **requisitos.md**
Documento detalhado com os **requisitos funcionais** para uma **API de Gerenciamento de Séries e Filmes**.

**Conteúdo:**
- 26 requisitos funcionais (RF01 a RF26)
- Histórias de usuário para cada requisito
- Comportamentos e resultados esperados
- Funcionalidades incluem:
  - Gerenciamento de listas de séries/filmes
  - Catalogação e busca de filmes
  - Sistema de aluguéis e devoluções
  - Lista de favoritos
  - Notificações de disponibilidade

### **agent_example.md**
Exemplo de como criar um **agente customizado**.

### **instructions_example.md**
Exemplo de **instruções customizadas** para aplicar padrões de código em todo o projeto.

### 🎯 **skill_example.md**
Exemplo de como criar uma **skill** (habilidade) customizada.
